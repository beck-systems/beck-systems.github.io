# beck-systems.github.io

Personal site for Brandon Beck — Salesforce, GTM systems, and AI enablement. Plain HTML, CSS, and a small theme script. GitHub Pages serves it from the root of the default branch at <https://beck-systems.github.io>.

## Preview locally

```bash
python3 -m http.server 4173
```

Then open <http://127.0.0.1:4173>.
